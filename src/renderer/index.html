Unstrung Application

Use the File menu, or press Alt then F, to open a song file. Each file opens in its own tab.

No files are open. Press Ctrl+T, or choose Open File… from the File menu, to open a song file. Once files are open, switch between tabs with the Left and Right arrow keys or Ctrl+Tab and Ctrl+Shift+Tab, and close the current tab with Ctrl+W.

Audio playback

Plays a synthesized audio rendering of the file open in the active tab.
