About Unstrung

Unstrung is an accessible, screen-reader-friendly viewer for song composition files, such as Guitar Pro tablature. It parses a file into its underlying data model — tracks, tuning, measures, time and key signatures, and more — and presents that information as plain, semantic HTML text and headings instead of a visual score, so it can be read and navigated entirely with a screen reader.

Supported file formats

  • Guitar Pro: .gp, .gpx, .gp5, .gp4, .gp3
  • MusicXML: .musicxml, .xml

Unstrung aims to make music software fully usable by blind musicians.

Unstrung is free and open source software, released under the MIT License. The source code is available on GitHub.

Guitar Samples

Plays real recorded notes of a green Gretsch guitar, ascending in pitch, using the Green Gretsch samples bundled with Unstrung.

Each note was recorded at multiple velocity layers — how hard the string was picked (soft, medium, or loud), which genuinely sound different from each other, not just quieter or louder — and several round robins: repeat takes of the same note and velocity, so a repeated note doesn't sound identical every time it's played.

Samples are from the Black And Green Guitars sample pack by Karoryfer Lecolds.

This sets how often a new note starts. Each note keeps ringing for about three times that long and fades out underneath the note that follows it, the way a plucked string carries on sounding rather than stopping the moment the next note is played.

Chord Practice

Generates a chord progression to play along with, and an audio track for it. The progression opens in its own tab, with every chord listed and its fingering and notes inside a collapsed region.

Chords are chosen from weights that follow how chords tend to move in a key, so a progression is different each time but still goes somewhere. Only chords playable at the experience level chosen are used.

Every progression reports the seed it was built from. Entering one here rebuilds that exact progression, so a sequence worth practising can be written down or passed on. The key, level and length must match the ones it was generated with.

Keys are listed only where enough chords can be played at the level chosen. Open position does not cover all twelve.

Songs rarely stay strictly inside one key. Most of what sounds like a chord from a neighbouring key is one of two things: a chord that points at the one after it, like the D7 before a G in a song in C, or a chord taken from the parallel minor, like a B flat or an F minor in C. Both are offered here. The frequent setting also reaches a second step around the circle of fifths, which starts to sound like the song has genuinely changed key rather than borrowed a colour.

These are the two numbers of a time signature: 4 and 4 is four quarter-note beats to the measure, 3 and 4 is a waltz, 6 and 8 is six eighth-note beats. The lower number changes how the time signature is written and read, not how fast it plays, because the tempo below is already counted in beats.

One chord to a measure, strummed on every beat. A chord may be held for two measures, the way a progression usually breathes, so a progression uses fewer distinct chords than it has measures.

    Settings

    There are no general settings yet.

    These settings will likely be useful if you read Unstrung with a screen reader. Each one reduces how much your screen reader has to read out, so none of them changes what the song is, only how much is said about it.

    When a beat strums a chord Unstrung can name, describe it with just the chord name and the stroke direction, leaving out the range of strings and any muted strings. If you already know the shapes, the name tells you those anyway. Beats that have no chord name are still listed string by string, since there is nothing shorter to say about them. Off by default.

    Close any expanded section, such as a track's measures, when you move away from its tab. Coming back to a tab that still has measures expanded can leave a screen reader unresponsive for several seconds while it takes in every beat again. With this on, you reopen only what you want. On by default.
