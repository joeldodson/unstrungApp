About Unstrung

Unstrung is an accessible, screen-reader-friendly viewer for song composition files, such as Guitar Pro tablature. It parses a file into its underlying data model — tracks, tuning, measures, time and key signatures, and more — and presents that information as plain, semantic HTML text and headings instead of a visual score, so it can be read and navigated entirely with a screen reader.

Supported file formats

  • Guitar Pro: .gp, .gpx, .gp5, .gp4, .gp3
  • MusicXML: .musicxml, .xml

Unstrung is part of the eyesunstrung project, which aims to make music software fully usable by blind musicians.

Unstrung is free and open source software, released under the MIT License. The source code is available on GitHub.

Guitar Samples

Plays real recorded notes of a green Gretsch guitar, ascending in pitch, using the Green Gretsch samples bundled with Unstrung.

Each note was recorded at multiple velocity layers — how hard the string was picked (soft, medium, or loud), which genuinely sound different from each other, not just quieter or louder — and several round robins: repeat takes of the same note and velocity, so a repeated note doesn't sound identical every time it's played.

Samples are from the Black And Green Guitars sample pack by Karoryfer Lecolds.

This sets how often a new note starts. Each note keeps ringing for about three times that long and fades out underneath the note that follows it, the way a plucked string carries on sounding rather than stopping the moment the next note is played.
